# Roadmap

## Implemented

- Bounded Go standalone WebSocket listener using `coder/websocket`.
- Origin/path validation, explicit connection admission, message bounds, context-aware I/O, and
  graceful shutdown.

## Release gates

- Hosted CI and supported Go version matrix.
- Autobahn protocol conformance and ingress interoperability.
- Multi-instance connection load, memory, tail-latency, and drain measurements.
- Signed artifacts and provenance.
